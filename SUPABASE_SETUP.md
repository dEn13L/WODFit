# Инструкция по настройке Supabase и запуску WOD FIT

## 1. Создание и настройка проекта в Supabase

1. Перейдите на [supabase.com](https://supabase.com) и войдите в консоль.
2. Нажмите **New Project**, выберите организацию, задайте имя проекта (например, `wod-fit`) и надежный Database Password.
3. Дождитесь создания проекта (около 1-2 минут).

---

## 2. Настройка Email Auth (Аутентификация)

1. В левом меню консоли Supabase перейдите в **Authentication** → **Providers**.
2. Убедитесь, что провайдер **Email** включен (**Enabled**).
3. (Для тестирования и локальной разработки) В разделе **Authentication** → **Providers** → **Email** отключите пункт **Confirm email**, чтобы пользователи могли входить сразу после регистрации без ожидания письма подтверждения.

---

## 3. Применение схемы базы данных (SQL Migration)

1. В левом меню Supabase откройте **SQL Editor**.
2. Нажмите **New query**.
3. Скопируйте и вставьте содержимое файла `sql/01_initial_schema.sql` из репозитория проекта.
4. Нажмите **Run**.
5. Запрос создаст:
   - Enum-типы: `user_role`, `workout_part_type`, `workout_status`, `result_status`.
   - Таблицы: `profiles`, `groups`, `group_members`, `workouts`, `workout_parts`, `workout_assignments`, `part_results`.
   - Индексы для ускорения выборок.
   - Триггер `on_auth_user_created` для автоматического создания профиля с ролью (`coach` или `client`) и именем при регистрации.
   - RPC-функцию `join_group_by_code` для безопасного вступления в группу по коду.
   - Row Level Security (RLS) политики разграничения доступа для атлетов и тренеров.

---

## 4. Получение ключей доступа

1. В левом меню перейдите в **Project Settings** → **API**.
2. Скопируйте:
   - **Project URL** (например, `https://abcdefghijklm.supabase.co`)
   - **anon / public key** (длинный JWT-токен в секции *Project API keys*)

---

## 5. Запуск приложения (Android / iOS / Web)

Передайте параметры `SUPABASE_URL` и `SUPABASE_ANON_KEY` через аргументы `--dart-define`:

### Команда запуска для Web:
```bash
flutter run -d chrome \
  --dart-define=SUPABASE_URL=https://ВАШ_ПРОЕКТ.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=ВАШ_ANON_KEY
```

### Команда запуска для Android:
```bash
flutter run -d android \
  --dart-define=SUPABASE_URL=https://ВАШ_ПРОЕКТ.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=ВАШ_ANON_KEY
```

### Команда запуска для iOS:
```bash
flutter run -d ios \
  --dart-define=SUPABASE_URL=https://ВАШ_ПРОЕКТ.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=ВАШ_ANON_KEY
```

## 6. Быстрый сценарий проверки функционала

1. **Регистрация тренера**:
   - Нажмите *Зарегистрироваться*.
   - Выберите роль **Тренер**, введите имя (например, «Иван Тренер»), email и пароль.
   - После регистрации откроется **Панель тренера**.

2. **Создание группы**:
   - Нажмите *Мои группы* → *Создать группу* (например, «Утренняя группа 08:00»).
   - Скопируйте сгенерированный 6-значный код приглашения (например, `CF78A1`).

3. **Создание и публикация тренировки**:
   - Нажмите *Новая тренировка*.
   - Введите название WOD, выберите группу для назначения, настройте части (Разминка, Силовой блок, WOD).
   - Нажмите *Опубликовать тренировку*.

4. **Регистрация атлета (клиента)**:
   - Выйдите из аккаунта тренера и зарегистрируйтесь с ролью **Атлет (Клиент)** (например, «Петр Атлет»).
   - В Личном кабинете нажмите *Вступить в группу по коду* и введите код `CF78A1`.
   - В списке тренировок появится опубликованная тренировка.

5. **Ввод и просмотр результатов**:
   - Откройте тренировку, нажмите *Записать результат* у части WOD, выберите Rx/Scaled, введите результат (например, `12:45`) и заметку.
   - Нажмите *Результаты группы* (иконка вверху справа) для просмотра сводки всех участников.
