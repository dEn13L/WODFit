# История безопасности, синхронизации и проверок

ИСТОРИЯ снимка 4fa4a19: датированные применения/аудиты и технические ограничения не проверялись заново. «14 не применялась» конфликтует с поздней live-сверкой: [реестр](live-db-status.md). Сохранять атомарность save_workout, ID заданий/assigned_at, запрет удаления задания с любыми результатами (включая tombstone), восстановление формы при отказе, каскад целой тренировки. Offline: UUID операций, LWW по client_updated_at затем UUID, backoff, удаление очереди лишь после server ack, изоляция аккаунтов. AppLogger — локальный маскированный журнал без отправки. Для двух устройств/manual UI доказательств нет.

Сохранённые блоки ниже — первоисточник, а не самостоятельные текущие инструкции. Нормативный приоритет — корневой AGENTS и явная задача.
