### Типографика
- Заголовки: Manrope 700–800.
- Текст: Manrope 400–500.
- Цифры результатов: JetBrains Mono / Space Mono 500–700.

### Компоненты
- Карточки: radius 20, elevation 0.
- Поля ввода: radius 12, border `#E2E8F0`.
- Кнопки primary: pill, radius 999.
- Бейджи: radius 10.

## Принятое решение по токенам
- Обязательные токены из AGENTS.md имеют приоритет: dark primary `#CCFF00`,
  light primary `#06B6D4`, destructive/publish `#EF4444`.
- Остальные токены взяты из брифа: dark background `#0C0F12`, surface `#171C21`,
  text `#F2F5F7`, muted `#98A2AD`, success `#34D399`, warning `#F59E0B`.
- Для вторичного текста тёмной темы используется более контрастный `#B4BDC7`;
  `#98A2AD` остаётся цветом подсказок.
- Отдельные font assets не подключаются: текущая иерархия достигается системным
  шрифтом и его начертаниями, результаты используют системный `monospace`.
  Это не добавляет вес Web-бандлу и новую зависимость.
- Белый текст на light primary `#06B6D4` сохраняется как обязательное продуктовое
  решение; его контраст ниже WCAG AA для обычного текста, поэтому этот токен
  используется только для крупных акцентных контролов.

## Подводные камни

### Темы и кэш
- Hot reload не применяет изменения темы — нужен hot restart (`R`) или перезапуск.
- Веб агрессивно кэширует бандл — после правок темы жёсткая перезагрузка (Cmd/Ctrl+Shift+R).
- Захардкоженные цвета удобно искать через Widget Inspector во Flutter DevTools.

### Миграции БД
- Строки enum в PostgreSQL должны точно совпадать с Dart-маппером.
- `ALTER TYPE ... ADD VALUE` работает, удалить значение нельзя без пересоздания типа.
- Переименования таблиц/колонок — через `ALTER ... RENAME`, данные сохраняются.

### Supabase RLS
- В RPC, которым нужно обойти RLS (вступление по коду), — `security definer`.
- Новая таблица: сразу включить RLS и создать политики.
- N+1 легко возникает при джойнах через client SDK — один запрос + джойн в памяти.

### Hive
- Только кэш и настройки, не бизнес-логика.
- `settings_box` — тема (ключ `theme_mode`), `workouts_box` — черновик формы.
- При изменении структуры данных в боксе нужна миграция или очистка.
