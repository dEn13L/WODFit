## Подводные камни

### Темы и кэш
- Hot reload не применяет изменения темы — нужен hot restart (`R`) или перезапуск.
- Веб агрессивно кэширует бандл — после правок темы жёсткая перезагрузка (Cmd/Ctrl+Shift+R).
- Захардкоженные цвета удобно искать через Widget Inspector во Flutter DevTools.

### Миграции БД
- Строки enum в PostgreSQL должны точно совпадать с Dart-маппером.
- `ALTER TYPE ... ADD VALUE` работает, удалить значение нельзя без пересоздания типа.
- Переименования таблиц/колонок — через `ALTER ... RENAME`, данные сохраняются.

### Supabase RLS
- В RPC, которым нужно обойти RLS (вступление по коду), — `security definer`.
- Новая таблица: сразу включить RLS и создать политики.
- N+1 легко возникает при джойнах через client SDK — один запрос + джойн в памяти.

### Hive
- Только кэш и настройки, не бизнес-логика.
- `settings_box` — тема (ключ `theme_mode`), `workouts_box` — черновик формы.
- При изменении структуры данных в боксе нужна миграция или очистка.
